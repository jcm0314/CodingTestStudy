실행 가능한 백엔드 프로젝트 하나를 만들어 줘.

목표는 프로젝트의 기능을 추가하는 것이 아니라, 실제 코드와 실행 환경을 조사하며 백엔드 엔지니어링 문제를 발견하고 해결하는 것이다.

조건:
1. Spring Boot와 관계형 데이터베이스를 사용하는 현실적인 서비스로 구성한다.
2. 핵심 API, 데이터 모델, 실행 방법, 환경 설정, 테스트 코드를 제공한다.
3. 프로젝트는 실제로 실행 가능해야 하며, 실행에 필요한 의존성과 설정을 명시한다.
4. 트랜잭션, 동시성, 데이터 정합성, 예외 처리, SQL 성능, 자원 관리, 보안 및 권한 검증 등을 조사할 수 있는 구조로 만든다.
5. 일부 문제나 설계상 위험이 존재할 수 있지만, 의도적으로 넣은 문제의 위치와 정답은 알려주지 않는다.
6. 문제를 발견하고 검증할 수 있도록 로그, 테스트, 실행 결과를 확인할 수 있게 한다.
7. 문제를 조사할 수 없는 불필요한 환경 오류나 무작위 컴파일 오류는 최소화한다.
8. 프로젝트의 기능과 규모는 혼자서 분석하고 개선할 수 있는 수준으로 제한한다.
9. 실행 방법과 기본 기능을 검증하는 방법을 먼저 제공한다.

프로젝트를 생성한 뒤에는 구현한 기능, 기술 스택, 실행 방법, 알려진 제약 사항만 요약한다. 숨겨진 문제의 위치나 정답은 공개하지 않는다.
